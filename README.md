# Tailwind CSS Gradient Generator

![Tailwind Gradient Generator Banner](public/banner.png)
Link: [Tailwind Gradient Generator](https://tailwind-gradient-generator.com/)

## About

Tailwind CSS Gradient Generator is a free online tool that helps developers and designers create beautiful CSS gradients using Tailwind CSS utility classes. With an intuitive interface, you can easily customize colors, directions, and positions to generate the perfect gradient for your web projects.

### Features

- Create linear gradients with from, via, and to color stops
- Choose from all Tailwind CSS colors
- Adjust shade intensity
- Set custom stop positions
- Copy generated CSS code with one click
- Save your favorite gradients
- Dark mode support

## Getting Started

Visit [https://tailwind-gradient-generator.com](https://tailwind-gradient-generator.com) to start creating beautiful gradients for your projects.

## Development

### Prerequisites

- Node.js 16 or higher
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/caoyx1990/tailwind-css-gradient-generator.git

# Navigate to the project directory
cd tailwind-css-gradient-generator

# Install dependencies
npm install

# Start the development server
npm run dev
```
